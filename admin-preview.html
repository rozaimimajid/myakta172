Tentang Dashboard Admin MyAKTA172

Prototaip pengurusan pakej MyAKTA172 oleh DigitalHubb.my. Semua rekod pengguna, resit dan kutipan adalah data simulasi. Belum ada integrasi pangkalan data, pengesahan Admin atau pembayaran sebenar.

Aplikasi utama MyAKTA172, lapan carta alir, teks Akta 172 dan cabang main tidak diubah oleh paparan ini.
